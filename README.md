# Machine Learning Course

Study materials for a machine learning course covering unsupervised learning (UML) and supervised learning (SML): interactive flashcards and reference tables from each lesson. The materials also prepare students for the **scikit-learn Associate Practitioner** certification by Probabl.

### [👉 Open the flashcards](https://samaardi.github.io/ml-flashcards/)

The key comparison tables from each lesson, collected in one place.

## How to use the flashcards

1. Pick the decks you want to study. Click **All decks**, or choose one or more decks by session.
2. Read the question and answer it in your head.
3. Tap the card (or press **Space**) to see the answer.
4. Be honest. Mark it **I knew it** or **Review again**.
5. Use **Only "review again"** to repeat just the cards you missed. Use **Shuffle** to mix the order.
6. **All cards** shows every question and answer as a list, for quick revision.

Keyboard shortcuts: `Space` flips the card, `←` `→` move between cards, `1` marks "Review again", `2` marks "I knew it".

Your progress is saved in your own browser only. Nobody else can see it, and it stays on the device you used.
